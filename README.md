## 📌 프로젝트 소개
비키니시티 104번 버스 정류장에서 하염없이 버스를 기다리던 중, 벤치에 우두커니 앉아있는 코끼리물범(자둔)을 마주쳤습니다.  
지루한 기다림의 시간 동안 코끼리물범이 엄선한 최고의 명작 영화들을 비주얼노벨 게임 스타일의 연출과 대화로 추천해줍니다.

---

## ✨ 핵심 기능 및 연출 컨셉

1. **비주얼노벨 게임 컨셉 장면 전환**:
   - **평상시 대화 모드**: 첫 번째 첨부 이미지(`idle_bench_seal.png`)를 배경으로 벤치에 앉은 코끼리물범과 정류장 분위기 속에서 대화합니다.
   - **영화 소개 모드**: 영화 추천 버튼이나 장르를 선택하면, 배경이 빈 벤치(`bg_bench_empty.jpg`)로 전환되며 코끼리물범 캐릭터(`seal_sprite.png`)가 원래 위치에서 화면 좌측으로 부드럽게 비켜서고, 화면 중앙에 영화 포스터와 정보 카드가 팝업됩니다.
   - **벤치로 복귀**: '벤치로 돌아가기'를 누르면 캐릭터가 다시 벤치로 이동하며 평상시 모드로 복귀합니다.

2. **풍부한 영화 데이터 (총 23편 엄선)**:
   - 영화 포스터, 제목(한글/원제/개봉연도), 상영시간, 별점(⭐), 감독 및 출연진
   - 줄거리 요약 소개
   - 코끼리물범만의 유쾌하고 철학적인 **한줄평(물범 피셜)**
   - 유튜브 공식 예고편 즉시 검색 연동 버튼

3. **장르별 영화 분류 및 필터링**:
   - `✨ 전체 (23편)`
   - `🚀 SF · 판타지 (4편)`
   - `💥 액션 · 모험 (4편)`
   - `🎨 애니메이션 (4편)`
   - `🎭 드라마 · 명작 (3편)`
   - `💖 로맨스 · 멜로 (3편)`
   - `😱 스릴러 · 미스터리 (3편)`
   - `🤣 코미디 · 힐링 (2편)`

4. **랜덤 영화 추천 버튼**:
   - 상단 헤더의 강조된 `[ 🎲 아무거나 골라줘! ]` 버튼
   - 대화창 및 영화 카드 내 다음 추천 버튼 지원

5. **인터랙티브 비주얼노벨 요소**:
   - **텍스트 타이핑 효과(Typewriter)**: 한 글자씩 출력되는 레트로 감성의 대사 연출 (클릭 시 즉시 스킵 가능)
   - **Web Audio API 사운드**: 타이핑 비프음, 카드 팝업 차임, 슬라이드 바람소리, 버튼 클릭음 (상단 헤더에서 켜기/끄기 가능)
   - **캐릭터 인터랙션**: 캐릭터를 콕 찌르면 흔들리는 애니메이션과 함께 재치 있는 속마음 말풍선 출력
   - **해저 분위기 연출**: 부드럽게 떠오르는 물방울 파티클 및 빛줄기 애니메이션

## 🛠️ 기술 스택
- **HTML5** (시맨틱 마크업, 접근성 고려)
- **Vanilla CSS3** (Glassmorphism, Flex/Grid 레이아웃, Keyframe Animation, Transition)
- **Vanilla JavaScript (ES6+)** (무의존성 순수 자바스크립트, Web Audio API 사운드 합성, 비동기 시퀀서)

2. 예시 (Python 내장 웹서버):
   ```bash
   python -m http.server 3000
   ```
